## 1. Trackly — система мониторинга эпилепсии

**Название:** Trackly (десктоп-приложение + публичный веб-сайт)

**Ссылка на GitHub/демо:** https://tracklyapp.xyz (продакшен-домен, HTTPS) · https://github.com/jaraslaukunin/trackly-site (публичная часть)

**Когда делал:** весна–лето 2026, активная поддержка продолжается (последний пуш — сентябрь 2026). Сайт: создан 2026-05-31, 11 коммитов. Десктоп: локальная история сжата, 22 коммита; SQL-миграции датированы июнем 2026.

**Задача — что решает:** персональное приложение для самостоятельного мониторинга состояния и ведения медикаментозного лечения пациентов с эпилепсией: дневник приступов, приём препаратов, обследования, напоминания, история болезни.

**Технологии:** C++, Qt 6 (включая macOS-слой Objective-C++), SQLite, Supabase (PostgreSQL), Supabase Edge Functions, Supabase-миграции, HTML/CSS/JS, GitHub Pages.

**Что сделал лично:** весь продукт соло — архитектура приложения, десктопный клиент (основное окно, календарь, drag&drop вложений обследований, экспорт отчётов, диалог авторизации, виджеты и стили), серверная часть на Supabase (Edge Functions, SQL-миграции), публичный сайт с юридическими документами и страницей статуса.

**Есть ли API / БД / авторизация / интеграции / автоматизация:**
- БД: PostgreSQL через Supabase + локальный SQLite в клиенте
- Авторизация: коды верификации через Edge Functions (`send-verification-code`, `verify-code`)
- Интеграции: Resend (доставка email), `emergency-email` (экстренная отправка), health-check эндпоинт через Edge Functions
- Автоматизация: скрипты упаковки под Windows (`package.bat`) и macOS (`package.sh`), авторазвёртывание сайта на GitHub Pages

**Результат в цифрах или фактах:**
- 4 локализации интерфейса: русский, английский, белорусский (кириллица), белорусская латинка — и в приложении, и на сайте
- 3 Supabase Edge Functions + SQL-миграции в репозитории
- 5 страниц публичного сайта (главная, privacy, consent, terms, status)
- Рабочий продакшен-домен tracklyapp.xyz с HTTPS и health-check страницей
- Примечание: исходники десктопного клиента пока не в открытом доступе (локальный репозиторий без remote)
